Tracing (this desk)

  • Genesis ADA flow — trace.genesis_reach: bounded reachability from all 14,505 Byron genesis outputs (depth ≤ 8, fan-out cap 50, wide txs recorded in trace.genesis_wide_tx). Rebuilt weekly, receipts in trace.build_receipt.
  • NIGHT token flow — night.flow: the complete, exact flow graph of every output that ever carried NIGHT, from the single mint tx. night.current_holders = holdings now. Rebuilt weekly, receipts in night.build_receipt.
  • Search — $handles resolve on-warehouse (CIP-68 + legacy); addresses/tx hashes get trace-aware summaries (/rpc/search).

Standing intelligence (runs by itself)

  • Liquidity Intel — hourly dormant/genesis-ADA wake-up detection (intel.dormant_moves, intel.liquidity_daily); daily 07:00 email digest; alerts on genesis moves or exchange-directed flow.
  • BEACN Monitor — every 2h: whale watch (≥1M ADA dormant moves, genesis first-moves, ≥250k toward tagged CEX deposits), treasury watch (≥1M ADA withdrawals), governance watch (new actions), anonymous pool-fleet watch.
  • Exchange labels — intel.exchange_address: community tracer-token deposit claims (59 addresses, 6 exchanges). The on-chain message is FACT; the attribution is STRONG_INFERENCE.

Governance & pools

  • Governance — governance.proposals, drep_votes, drep_registry, proposal_vote_power (stake-weighted tallies), treasury_flow (true per-epoch inflow). Refreshed every 2h.
  • Pool operator clusters — poolsync.cluster: multi-pool operators found by synchronized KES rotations (operational control, STRONG_INFERENCE). Weekly rebuild.
  • Ledger Scrolls — scrolls.onchain: live verify of the on-chain library registry.

Raw chain (read-only replica)

  • Full db-sync schema at mainnet tip (public.*, 75 tables, logical replication from the relay) — blocks, txs, UTxOs, assets, certificates, rewards. This is what everything above is derived from.

API quick reference

  • GET /rpc/search?q=$beacn
  • GET /rpc/resolve_handle?h=$beacn
  • GET /rpc/address_summary?a=addr1…
  • GET /rpc/tx_summary?h=<64-hex>
  • GET /rpc/genesis_overview · /rpc/genesis_roots?p_limit=50 · /rpc/trace_children?p_tx_id=…&p_out_index=… · /rpc/trace_parents?p_tx_id=…
  • GET /rpc/night_overview · /rpc/night_roots · /rpc/night_children?… · /rpc/night_parents?…
  • GET /rpc/genesis_top_current · /rpc/night_top_holders
  • tables: /genesis_reach?address=eq.addr1… (schema trace is default; others via Accept-Profile header: governance, explorer, intel, scrolls, poolsync, night)
Evidence discipline: this desk shows on-chain flow — reachability, custody patterns, and delegation. It never proves real-world ownership, identity, or intent. Grade claims FACT / STRONG_INFERENCE / WORKING_HYPOTHESIS before repeating them. Data: abcde warehouse replica, receipts on every rebuild.
